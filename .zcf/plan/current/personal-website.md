# 个人网站开发计划

## 任务描述
创建一个GitHub个人网站，包含：
- 主页：个人详细介绍 + 影集（极简风格）
- 技术博客板块：极简赛博朋克工业风
- 生活感悟分享：星露谷像素风格
- GitHub版本控制 + Vercel部署配置

## 技术方案
方案1：纯 HTML + CSS + JavaScript（原生）

## 项目结构
```
personal-web/
├── index.html              # 首页（个人介绍）
├── blog.html              # 技术博客（赛博朋克风）
├── life.html              # 生活感悟（星露谷像素风）
├── css/
│   ├── main.css           # 首页样式
│   ├── blog.css           # 博客样式
│   └── life.css           # 生活样式
├── js/
│   └── main.js            # 交互逻辑
├── images/                # 图片文件夹
├── .github/
│   └── workflows/
│       └── deploy.yml     # 自动化工作流
├── .gitignore             # Git忽略文件
└── README.md              # 项目说明
```
